## 🚀 Paso a paso para publicar en GitHub Pages

### PASO 1 — Crear cuenta en GitHub
1. Ir a **https://github.com**
2. Clic en **Sign up**
3. Completar: nombre de usuario, correo, contraseña
4. Verificar el correo recibido
5. ✅ Cuenta lista

---

### PASO 2 — Crear el repositorio
1. Iniciar sesión en github.com
2. Clic en el botón verde **New** (o **+** → *New repository*)
3. Completar:
   - **Repository name:** `chekia-electoral-2025`
   - **Description:** `Honduras en año electoral: bulos y discursos de odio`
   - Seleccionar **Public** ← obligatorio para GitHub Pages gratuito
   - ✅ Marcar **Add a README file**
4. Clic en **Create repository**
5. ✅ Repositorio creado

---

### PASO 3 — Subir los archivos
1. Dentro del repositorio, clic en **Add file** → **Upload files**
2. Arrastrar o seleccionar los dos archivos:
   - `index.html`
   - `README.md`
3. En **Commit changes** escribir: `Publicar sitio Chekiá electoral 2025`
4. Clic en **Commit changes**
5. ✅ Archivos subidos

---

### PASO 4 — Activar GitHub Pages
1. Ir a **Settings** (pestaña con ícono ⚙️)
2. Menú izquierdo → clic en **Pages**
3. En **Source** seleccionar:
   - Branch: **main**
   - Folder: **/ (root)**
4. Clic en **Save**
5. Esperar **1 a 3 minutos**
6. Aparece: *"Your site is live at https://TU-USUARIO.github.io/chekia-electoral-2025/"*
7. ✅ Sitio publicado

---

### PASO 5 — Verificar y compartir
1. Abrir: `https://TU-USUARIO.github.io/chekia-electoral-2025/`
2. Probar en celular — el sitio es completamente responsivo
3. Compartir el enlace

## ❓ Preguntas frecuentes

**¿Necesito subir Chart.js por separado?**
No. Los gráficos se cargan automáticamente desde internet (CDN). Solo necesitas el `index.html`.

**¿El sitio funciona sin internet?**
Los gráficos no se mostrarán sin conexión porque Chart.js se carga desde CDN. Para uso offline habría que descargar Chart.js localmente.

**¿Puedo cambiar el nombre del repositorio?**
Sí, en Settings → General → Repository name. La URL cambiará también.

**¿Cuánto cuesta?**
Cero. GitHub Pages es completamente gratuito para repositorios públicos.
